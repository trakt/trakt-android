## Design Context

### Users

Trakt users track movies, TV, viewing habits across devices. Android footprint:

- **Phone / tablet (`app`)** — daily driver. Quick logging, calendars, recommendations, watchlists. Adaptive layouts honour window size classes.
- **Android TV (`tv`)** — lean-back. Trending content, episode details, 10-foot summaries, remote navigation. Full Compose (no Leanback fragments).
- **Widgets, notifications** — at-a-glance progress, "next episode" prompts via standard Android widget surfaces.

Job mirrors web + iOS: stay organised, discover content, feel on top of entertainment life. Android adds expectation of **natively Material 3 + adaptive Compose** — gestures, ripples, motion, adaptive layouts feel correct on platform.

### Brand Personality

**Clean, confident, modern.** Polished, premium, not flashy. Purple = brand anchor. Android surfaces honour Material 3 conventions, express Trakt identity through `TraktTheme` design tokens.

### Aesthetic Direction

- **Visual tone**: clean, confident. Strong hierarchy, generous whitespace, purposeful colour accents. Content (posters, artwork) = visual star — UI chrome stays out of way.
- **Theme**: full light/dark. Subtle purple tinting in dark mode. Seasonal overrides (Halloween → orange, Christmas → red) flow through Firebase Remote Config + `CustomThemeUseCase`; apply through `TraktTheme` tokens, never raw `Color(0xFF…)` at call sites.
- **Anti-references**: no cluttered dashboards, gamified UI, spreadsheet feel. No generic streaming-app aesthetics. No playful/childish — Trakt = confident, modern tool.
- **TV specifically**: 10-foot legibility. Honour Compose `tv-material` focus styles. Don't fight D-pad gesture vocabulary.

### Design Principles

1. **Content is king** — posters, artwork, media metadata = visual centrepiece. UI chrome recedes, lets content breathe.
2. **Purposeful colour** — purple = brand anchor. Red/blue/green/orange serve specific semantic roles (actions, trends, status). Never colour for decoration.
3. **Consistent rhythm** — use `TraktTheme.spacing` and `TraktTheme.size` tokens religiously. Adaptive tokens vary with window size class for phone/tablet/TV behaviour.
4. **Respect the user** — Material 3 dynamic colour where appropriate, `Modifier.semantics` for accessibility, reduced motion honours system preferences, WCAG AA contrast.
5. **Themed by design** — every colour works across light, dark, seasonal themes. Use semantic tokens (`TraktTheme.colors.textPrimary`), never raw `Color(0xFF…)` in feature code.
6. **Native feel** — Material 3 components, system fonts, platform haptics, Compose built-in motion. Custom flourish welcome but never at cost of un-Android feel.

### Technical Design Constraints

- **UI framework**: Jetpack Compose for **all** new code. No XML layouts.
- **Components**: design-system primitives in `common/.../ui/` exposed through `TraktTheme`. Variants via enum-typed parameters + dedicated `Modifier` extensions.
- **Tokens**: all visual values via `TraktTheme.{colors,typography,spacing,size}`. No raw hex/`Color(0xFF…)`/magic-number paddings in feature code.
- **Responsive**: phone/tablet/foldable adaptive layouts via window size classes (`androidx.compose.material3.adaptive`). TV uses focus-driven layout.
- **Typography**: Material 3 typography overridden through `TraktTheme.typography`; semantic styles (`title`, `body`, `label`, `tag`) keep parity with iOS and web.
- **Accessibility**: WCAG AA contrast. Animations respect `LocalAccessibilityManager` reduced-motion. Dynamic font scale honoured where practical.
